## 更新内容

- 当前段位和 RR 优先采用名片接口的有效数据，避免主角色资料中的旧段位覆盖名片已经更新的段位。
- 名片中的段位或 RR 缺失、无效时，分别回退到主角色数据；合法的 0 分正常显示。
- 段位仍按接口明确名称显示，不根据 RR 推算；图标继续来自名片，今日胜负和上一局加分继续来自战绩。
- 名片请求失败时保留上次完整数据，并显示过期状态，延续原有故障保护。

例如主角色仍返回“神话III”，名片已返回“辐能战魂 1250分”，现在显示“辐能战魂 1250 RR”。如果名片本身尚未同步，仍会显示接口返回的名称。

## 使用

下载并完整解压 `Valorant-CN-OBS-Overlay-Windows-x64.zip`，运行 `启动段位Overlay.bat`。OBS 地址仍为 `http://127.0.0.1:8787/overlay`，建议尺寸 420×120。

更新前关闭旧版程序，将新版文件覆盖到原目录；保留原目录的 `.data` 文件夹以继续使用本机登录缓存。不要上传或分享 `.data`。发布包只包含程序、源码、脚本、说明和许可证，不包含用户登录数据。

旧版 Release、下载附件和已有标签均保留。
