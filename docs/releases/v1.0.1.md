## 更新内容

- 修复未定级账号可能显示数字段位编码的问题，优先使用明确的段位名称。
- 修复高段位累计 RR 文本解析，支持超过 100 和 1000 的积分，避免长数字被截断。
- 区分接口请求失败、段位/RR 解析缺失与本机页面读取失败；请求失败保留上次展示数据。
- 删除未使用的角色字段、登录函数返回值及战绩列表重复转换。
- 补齐发布包中的诊断与测试说明文档。

## 验证

- Go 回归测试通过，包含 1,501 个合成段位/RR 集成用例，以及空战绩、单页、跨天和三页上限检查。
- 前端 4 项回归检查和 `go vet ./...` 通过。
- Windows x64 构建及版本入口检查通过。
- 合成测试不代表真实神话、辐能账号接口已完成在线验证。

## 使用

下载并完整解压 `Valorant-CN-OBS-Overlay-Windows-x64.zip`，运行 `启动段位Overlay.bat`。OBS 浏览器源地址仍为 `http://127.0.0.1:8787/overlay`，建议尺寸 420×120。

更新前关闭旧版程序。登录缓存保留在本机 `.data` 文件夹，请勿上传或分享该文件夹。发布包只包含程序、源码、脚本、说明和许可证，不包含用户登录数据。
