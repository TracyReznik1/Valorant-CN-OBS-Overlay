## 更新内容

- 新增 **macOS 12+** 支持，同时构建 Apple Silicon（arm64）与 Intel（amd64）版本。
- macOS 凭证使用 **Keychain + AES-GCM**；Keychain 不可用时回退到数据目录内 `0600` 本地密钥文件，凭证文件本身不是明文。
- macOS 数据目录改为 `~/Library/Application Support/ValorantCNOverlay`，单实例使用 `flock`，打开二维码/浏览器使用系统 `open`。
- 新增 macOS 启动器：`启动段位Overlay.command`、`重新登录.command`、`诊断.command`。
- 纳入 v1.1.0 的界面与运行改进：游戏内段位图标徽章（无额外背景圆圈/底座，徽章与卡片背景均按段位主色和上一局胜负渐变着色）、从本次软件启动后开始统计的上一局/连胜连败与呼吸脉冲动画、全简体中文文案、`/status` 状态页、显式重新登录、`--diagnose`、原子凭证写入、启动重试与后台不自动扫码。
- 补全 QQ 二维码状态码处理（`65` 失效、`53` 取消、`66/67` 继续轮询）；修复开发过程中一度把 `67` 误判为失效的回归。二维码真正过期时自动刷新。

## 使用

- Windows：解压后双击 `启动段位Overlay.bat`。
- macOS：解压后右键 `启动段位Overlay.command` → 打开。首次可能被 Gatekeeper 拦截，可执行 `xattr -dr com.apple.quarantine <解压目录>`，或从源码构建。
- OBS 地址仍为 `http://127.0.0.1:8787/overlay`，状态页为 `http://127.0.0.1:8787/status`。

## 已知限制

- 发布包没有 Windows 代码签名，也没有 macOS notarization；SmartScreen/Gatekeeper 可能提示未知开发者。
- 真实在线验证只覆盖一个账号；神话/辐能等高段位结构仍需更多样本。
- macOS Intel 版本只完成交叉构建，未在 Intel 机器上启动测试。
